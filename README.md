# 📻 Radio Player - Android Accessibility App for Visually Impaired Users

---

## 📖 About This Application

This repository contains a complete **Android radio streaming application** built with **Jieshuo+** (a screen reader for visually impaired users) using the AndroLua framework. The app is specifically designed with **accessibility in mind**, making it easy for blind and visually impaired users to navigate and control radio playback.

### 🎯 Project Goal

> *"Enable visually impaired listeners to access Islamic radio content using a simple, accessible tool without installing heavy applications that consume phone storage and memory."*

---

## ♿ Accessibility Features

| Feature | Description |
|---------|-------------|
| **Jieshuo+ Integration** | Fully compatible with the Jieshuo+ screen reader |
| **Voice-Announced Controls** | Buttons and menus are read aloud |
| **Simple Navigation** | Minimal UI with clear, large buttons |
| **Spoken Feedback** | Station changes and playback status are verbalized |
| **Accessible Settings** | All options can be navigated using screen reader gestures |
| **Large Touch Targets** | 48dp minimum touch areas |
| **High Contrast** | Optimized for users with partial vision |
| **Keyboard Support** | Can be operated with external keyboards |

---

## 🎮 Key Features

- ✅ **Multi-Language Support**: Arabic, English, and Persian with text-to-speech compatibility
- ✅ **10 Islamic Radio Stations**: Including Al-Siraj, Quran, Husayniyat, and more
- ✅ **Smart Playback Controls**: Play/Pause, Next/Previous station navigation
- ✅ **Sleep Timer**: Automatic shutdown after 30 minutes
- ✅ **Auto-Play**: Resume playback when reopening the app
- ✅ **Persistent Settings**: Save language preferences and station selection
- ✅ **Background Playback**: Continues playing when screen is locked
- ✅ **Developer Information**: Built-in about section with contact details
- ✅ **Screen Keep-Alive**: Prevents screen timeout during playback
